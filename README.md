# Eye of the Beholder – remake

Remake **Eye of the Beholder 1** (Westwood / SSI, 1991) postavený v Godotu 4.7 nad
originálními daty hry.

## Stažení

Hotová hra pro Windows je v [Releases](../../releases). Stačí rozbalit a spustit
`Eye of the Beholder.exe` – balíček obsahuje všechno, co hra potřebuje. Uložené pozice
a nastavení si hra ukládá do podsložky `save` vedle sebe.

## Ovládání

| | |
|---|---|
| šipky, WASD | pohyb a otáčení |
| myš | ovládání rozhraní, sbírání a házení předmětů |
| C | tábor |
| F2 / F4 | uložit / načíst hru |
| F5 | režim obrazu (syrové pixely, CRT, vyhlazení) |
| F6 | přepnutí mezi originální a přeškálovanou grafikou |
| F7 | rozvržení: široké nebo jako v originále |

## Co je ve hře

Všech dvanáct pater, původní pravidla AD&D i texty z `EOB.EXE`, skripty úrovní, příšery
bojující v reálném čase, kouzla, tábor, tvorba postav, úvodní sekvence i závěr hry.

Navíc proti originálu: přeškálovaná grafika, širší rozvržení, automapa kreslená grafikou
z Lands of Lore a vracení vržených zbraní tomu, kdo je hodil (dá se vypnout v *Preferences*).

## Co zatím chybí

Několik zvuků (okolní zvuk podzemí, výbuch magické střely, dopad hozeného předmětu, zvuky
animovaných sekvencí) a klávesa Esc ve hře zatím nic nedělá – hru ukončíš přes tábor,
*Game Options → Quit Game*.
